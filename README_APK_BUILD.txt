نسخه آماده ساخت APK اندروید برای پروژه پایش درختان شهرضا

تغییر جدید:
- منطقه/ناحیه
- نوع محدوده
- نام خیابان/بلوار/بوستان
- بخش/قطعه/محدوده فرعی
- سمت مسیر
- نقطه مرجع
- امکان ورود تک‌تک یا گروهی فهرست رسمی شهرداری از داخل تنظیمات
- گزارش بحرانی بر اساس ناحیه/خیابان/بخش
- این اطلاعات در Excel نیز ستون جدا دارند.

عمداً هیچ نام خیابانی از طرف برنامه حدس زده نشده است. وقتی فهرست رسمی را دارید، از بخش تنظیمات وارد کنید.

این ZIP را Extract کنید و همه محتویات آن، شامل پوشه مخفی .github، را در ریشه Repository آپلود کنید.
