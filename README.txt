اپلیکیشن پایش درختان شهرضا – نسخه MVP
=========================================
این بسته یک PWA قابل نصب روی موبایل است.

قابلیت‌ها:
- ثبت درخت، GPS، عکس، سلامت تاج/تنه/ریشه، آفت و بیماری، آبیاری، خطر، گروه مدیریتی و اقدام
- محاسبه خودکار امتیاز اولویت و سطح خطر
- کار آفلاین و ذخیره روی همان گوشی
- جستجو و ویرایش رکوردها
- داشبورد اولیه
- خروجی Excel (.xls)، CSV و پشتیبان JSON
- قابلیت نصب به شکل اپ از مرورگر پس از میزبانی روی HTTPS

نکته مهم:
برای نصب واقعی PWA و استفاده چند تیم، فایل‌ها باید روی یک آدرس HTTPS قرار گیرند (مثلاً GitHub Pages).
نسخه فعلی داده هر گوشی را جداگانه ذخیره می‌کند. برای تجمیع زنده چند تیم، در نسخه بعدی باید Backend/Database اضافه شود.
