نسخه ۰.۳ سامانه شناسنامه درختان شهرضا

مدل کاربران:
- اولین کاربری که ثبت‌نام می‌کند می‌تواند مدیر اولیه شود.
- کاربران بعدی به صورت کارشناس ایجاد می‌شوند.
- مدیر از تب «تیم» می‌تواند نقش کاربران را مدیریت کند.
- تعداد کارشناسان محدود به ۴ یا ۵ نفر نیست و بعداً قابل افزایش است.

ذخیره اطلاعات:
- هر رکورد ابتدا روی گوشی ذخیره می‌شود.
- در صورت وجود اینترنت، رکورد با Supabase همگام می‌شود.
- در قطع اینترنت، ثبت ادامه پیدا می‌کند و رکورد «در انتظار» می‌ماند.
- بعد از اتصال، همگام‌سازی دستی یا خودکار انجام می‌شود.
- اطلاعات متنی همه رکوردهای سرور روی گوشی کاربران کش می‌شود.
- عکس ثبت‌شده روی گوشی ثبت‌کننده باقی می‌ماند و یک نسخه نیز روی سرور آپلود می‌شود.
- فایل پشتیبان JSON مستقل از سرور قابل دریافت است.

نکته:
برای نصب نسخه ۰.۳ روی نسخه قبلی ممکن است به علت کلید امضای Debug لازم باشد نسخه قبلی حذف شود. قبل از استفاده میدانی، امضای ثابت برنامه را تنظیم می‌کنیم تا آپدیت‌های بعدی بدون حذف انجام شوند.
